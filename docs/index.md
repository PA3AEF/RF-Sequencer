# RF‑Sequencer Documentation

Welcome to the documentation for the **RF‑Sequencer** — a modular, safe, and hackable RF transmit/receive sequencer inspired by classic designs and reimagined for modern stations.

## Summary

The RF‑Sequencer monitors PTT and RF sensors, sequences relays and PA enable lines, computes VSWR and other derived values, and enters a conservative Safe Mode on faults. The repository contains documentation and quickstart material to get a unit running.
